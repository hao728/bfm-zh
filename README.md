# BFM 中文美化版

> Banner File Manager 的中文增强分支，专为 Winlator / Wine 桌面环境优化。

基于 [The412Banner/banner-file-manager](https://github.com/The412Banner/banner-file-manager) v1.2.1 开发，遵循 GPL-3.0 协议。

---

## 主要特性

### 文件管理
- **双面板**：左右独立浏览，支持跨面板复制/移动
- **拖拽操作**：面板内、面板间、拖入外部程序（如 AlphaRom 等）
- **四种视图**：大图标 / 小图标 / 列表 / 详细信息，设置自动持久化
- **收藏夹**：快速访问常用目录，独立彩色星标图标
- **预览窗格**：图片缩略预览、文本内容预览

### 智能图标
- **图片文件**：自动生成缩略图预览
- **格式识别**：音乐、视频、压缩包、文档、表格、演示、脚本、配置等均有独特图标
- **exe 图标增强**：优先从 exe 直接提取，失败自动查找同目录 `.ico`，解决 Wine 下图标丢失问题
- **图标缓存**：三级缓存机制，滚动流畅不卡顿

### 压缩包操作（需 7-Zip）
- 解压到当前文件夹 / 解压到同名文件夹
- 测试压缩包完整性
- 压缩为 ZIP / 7Z（支持文件、文件夹、多选）
- 解压进度窗口实时显示

### 游戏启动辅助
- **加速启动**：均衡模式 / 激进模式，清理内存后启动
- **启动参数预设**：窗口化、全屏、无边框、DX11、D3D9、Vulkan、单线程等，支持自定义参数
- **转区启动**：实验性功能，适用于日区游戏（可能与容器编码设置冲突）
- **提取图标**：从 exe 提取图标保存为 BMP

### 系统工具
- 哈希计算（MD5 / SHA 系列）
- 批量重命名
- 新建文件（txt / bat / reg）
- 双面板内容对比
- 文件关联管理器
- 调用 Winlator 自带任务管理器

### 界面优化
- 完整中文汉化（同时保留英文/葡萄牙语/俄语）
- 深色主题
- 字体大小可调
- 存储信息显示开关
- 磁盘容量条详细显示

## 安装方法

### 方式一：自动安装（推荐）
1. 下载发布包 `bfm-zh-x64.zip`
2. 解压后运行 `安装.bat`
3. 脚本自动备份原版、复制文件、重启 WFM

### 方式二：手动覆盖
1. 将 `wfm.exe` 和 `libcdio.dll` 复制到 Winlator 的 WFM 目录
2. 覆盖原有文件（建议先备份）

### 7-Zip 部署（解压/压缩功能必需）
- 自动安装脚本会检测并部署 7-Zip
- 手动方式：将 `7z.exe` + `7z.dll` 放入 `Z:\opt\apps\7-Zip\`
- 下载地址：[7-Zip 官方](https://www.7-zip.org/)（推荐 26.03 或更新版本）

## 卸载还原

运行 `卸载还原.bat`，自动恢复备份的原版文件。

## 实验性功能说明

以下功能正在测试中，可能因游戏/容器配置不同而效果不一：

- **转区启动**：通过设置环境变量模拟日区，部分 Galgame 可用，但可能与容器 `LC_ALL` 冲突
- **自适应窗口/全屏**：通过启动参数控制显示模式，部分游戏可能不支持
- **加速启动**：清理内存后启动游戏，效果因游戏而异，激进模式可能导致不稳定
